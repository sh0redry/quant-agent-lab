# 评价协议 v0（冻结）

- **版本：**v0
- **冻结日期：**2026-10-22
- **适用范围：**路径 B 下的本地运行；**非官方协议**
- **机器可读版本：**`configs/protocol.yaml`（本轮实验以该文件为准）

## 0. 使用规则

本协议是与官方设置**有差异**的自定协议。每一条都标注来源：

- **官方**：论文明确写出，可直接引用；
- **未知**：论文未写或无法核实；
- **自定**：我们为了先跑通而设定的值。

任何报告都必须写明"自定"项，不得把自定项描述成官方设置。

## 1. 题目与版本

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 100 题 | 不可取得 | 未知 |
| 本轮题目 | 3 道**合成夹具题**（fc-01..fc-03），仅验证链路，不进入任何成绩报告 | 自定 |
| 真实开发题 | 待定：BigFinanceBench 或 Finance Agent Benchmark v2 | 未知 |
| 版本控制 | 每题带 `version` 字段与文件 SHA-256，改动即升版本 | 自定 |

## 2. 可访问资源

| 项 | 结论 | 标签 |
|---|---|---|
| 官方工具集 | 论文只说是 harness 的工具，未列白名单 | 未知 |
| 本轮权限 | 仅：本地夹具目录读取、夹具内关键词检索、四则运算；**无网络** | 自定（比官方更严） |
| 越权 | 任何路径逃逸、网络访问一律判为运行错误并记录 | 自定 |

## 3. 信息截止时间

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 每条 query 固定一个 cutoff，rubric 中的数值以截止日为界（p.4、p.24） | 官方 |
| 本轮 | 每道夹具题声明 `as_of`；夹具内不放该日期之后的信息 | 自定 |
| 检查 | 报告中单独标注"是否可能使用截止日后信息"；夹具题默认无此风险 | 自定 |

## 4. 工具与计数

| 项 | 结论 | 标签 |
|---|---|---|
| 工具 | `read_evidence`、`search_evidence`、`calculate`、`submit` | 自定 |
| step 计数 | 一次模型调用 = 1 step（含工具调用回合） | 自定 |
| 工具调用计数 | 每个工具调用单独计 1 次 | 自定 |
| 重试 | 仅工具异常可重试，上限 1 次；模型调用失败不重试，直接记失败 | 自定 |

## 5. 预算与终止

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 题目级预算与终止规则只作概述，具体值未知 | 未知 |
| 本轮 | `max_steps = 8`，`max_tool_calls = 16`，`timeout = 300s` | 自定 |
| 费用 | mock provider 为 0；真实模型轮次按实际 token 计价并记录 | 自定 |
| 终止原因 | `submitted`／`max_steps`／`max_tool_calls`／`timeout`／`error`，逐条落入 trace | 自定 |

## 6. 裁判可见范围

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 裁判看到完整 trace（消息、工具调用、工具结果）＋最终答案（p.6） | 官方 |
| 本轮 v0 | 裁判只看**最终答案**（更严格，先排除"过程分"） | 自定 |
| 后续 | v1 增加"仅答案 vs 答案+trace"的对照，量化过程信息的贡献 | 自定 |

## 7. 评分与聚合

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | rubric 合计 100 分，四维（量化／事实／论证／格式） | 官方（结构） |
| 本轮 | 逐项二值判定，权重之和为 100，总分 = 通过项权重之和 | 自定 |
| 未完成 | `submit` 未调用则分数记 0，但在汇总中单独列为"未完成"，不与答错混同 | 自定 |
| 聚合 | 报告总分、分项通过率、完成率、工具错误数；不跨系统比较 | 自定 |

## 8. 重复与复核

- 本轮 mock 运行确定性，不需要重复；真实模型轮次每题至少 3 次（plan §9.2）。
- 人工复核：至少抽 1 例逐步对照夹具与答案，记录分歧。
- 评分争议与 Agent 错误分开统计（E7）。

## 9. 冻结方式

`configs/protocol.yaml` 的内容与 SHA-256 写入每次运行的 `config.json`，运行后不得修改同版本协议；如需变更，升到 v1 并重跑。
