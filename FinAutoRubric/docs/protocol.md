# 评价协议 v0.2（冻结）

- **版本：**v0.2（替代 v0.1）
- **冻结日期：**2026-10-22
- **适用范围：**路径 B 下的本地运行；**非官方协议**
- **机器可读版本：**`configs/protocol.yaml`（以该文件为准）
- **变更原因：**回应 `docs/review.md`；详见文末变更记录

## 0. 使用规则

本协议与官方设置**有差异**。每一条都标注来源：**官方**（论文明确）／**未知**（论文未写）／**自定**（我们先跑通所设）。

任何报告都必须写明"自定"项，不得把自定项描述成官方设置。

## 3. 信息截止时间

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 每条 query 固定一个 cutoff，rubric 中的数值以截止日为界（p.4、p.24） | 官方 |
| 本轮 | 每道夹具题声明 `as_of`；**夹具可以故意放入截止日之后的材料作为干扰项**，并在 `question.json` 的 `post_cutoff_material` 中显式登记 | 自定 |
| 检查 | 评分表独立检查答案；`cutoff_compliance` 记录规范化读取路径及搜索命中的截止日后材料。`violated` 表示工具已暴露该信息，`clean` 仅表示未观察到登记材料的暴露，不证明答案没有使用未来信息 | 自定 |

> 修正记录：v0 曾声称"夹具内不放截止日之后的信息"，但 fc-02 实际包含了 2025-02-20 的新闻稿（截止日 2025-02-04）。v0.1 改为：干扰项是设计的一部分，必须登记并按条目评分。

## 4. 工具与计数

| 项 | 结论 | 标签 |
|---|---|---|
| 工具 | `read_evidence`、`search_evidence`、`calculate`、`submit` | 自定 |
| step 计数 | 一次模型调用 = 1 step | 自定 |
| 工具调用计数 | 每个工具调用计 1 次；重试**不**另计一次工具调用，另记 `retries` | 自定 |
| 重试 | 仅工具错误可重试，**每个工具调用最多 1 次**；重试后仍失败则记 `errors` | 自定 |

## 5. 预算与终止

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 题目级预算与终止规则只作概述，具体值未知 | 未知 |
| 本轮 | `max_steps = 8`、`max_tool_calls = 16`、`max_tool_retries = 1`、`timeout = 300s` | 自定 |
| 超时执行 | 剩余时间传入 `provider.complete(timeout=...)`；模型调用前后及每次工具尝试前后（含重试）核对 deadline；超时后不重试、不接受提交。当前为协作式截止检查，不能强制中断执行中的工具 | 自定 |
| CLI 退出码 | 无匹配题目或任一 episode 未完成时返回 1；全部完成时返回 0。低分与未完成分开处理 | 自定 |
| 费用 | mock 为 0；真实模型记录 provider 返回的 usage，若配置了 `pricing` 则估算费用 | 自定 |
| 终止原因 | `submitted`／`max_steps`／`max_tool_calls`／`timeout`／`error`，逐条落入 trace | 自定 |

## 6. 裁判可见范围

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | 裁判看到完整 trace（消息、工具调用、工具结果）＋最终答案（p.6） | 官方 |
| 本轮 v0.2 | 裁判只看**最终答案** | 自定 |
| 说明 | 这两种是**不同的测量方式**：只看答案会漏掉"过程里做对但没写出来"，看 trace 会奖励过程。不能称哪一种"更严格"，只能说明差异 | — |

## 7. 评分与聚合

| 项 | 结论 | 标签 |
|---|---|---|
| 官方 | rubric 合计 100 分，四维（量化／事实／论证／格式） | 官方（结构） |
| 本轮 | 逐项二值判定，权重之和为 100，总分 = 通过项权重之和 | 自定 |
| 数字判定 | 支持中文紧邻数值、千分位、括号负数、全角数字；归一化后掩码 ISO 日期。`near` 要求同一分句内“指标标签＋连接词＋数值”，`unit` 可限制数值后紧邻单位；不支持一般性单位换算、期间指代或语义归属推断 | 自定 |
| 未完成 | 未 `submit` 则分数记 0，并在汇总中单列"未完成" | 自定 |
| 聚合 | 报告总分、分项通过率、完成率、工具错误、重试次数、截止日合规、usage；不跨系统比较 | 自定 |

## 8. 重复与复核

- mock 运行确定性，不需要重复；真实模型每题至少 3 次（plan §9.2）。
- 人工复核至少 1 例，记录分歧。
- 评分争议与 Agent 错误分开统计（E7）。

## 9. 冻结方式

`configs/protocol.yaml` 的内容与 SHA-256 写入每次运行的 `config.json`；运行后不得修改同版本协议，变更需升版本并重跑。
